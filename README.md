# Port Scanner & Host Checker 🚀

Un outil simple de vérification d'hôtes et de scan de ports TCP développé en Python. Projet réalisé dans le cadre de l'apprentissage des réseaux et de la cybersécurité.

## Fonctionnalités 🛠️
- **Vérification d'hôte (Ping)** : Teste si une machine est active sur le réseau via des paquets ICMP (`subprocess`).
- **Scan de ports TCP** : Vérifie l'état de ports spécifiques en utilisant les sockets bas niveau (`socket`).
